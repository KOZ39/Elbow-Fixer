# Elbow Fixer

English | [한국어](README_KO.md) | [日本語](README_JA.md)

> A non-destructive elbow and forearm twist correction tool for VRChat avatars.

## Requirements

- Unity 2022.3.22f1

## Installation

Click "Add to VCC" on the [VPM listing](https://koz39.github.io/vpm-listing/) to add the repository, then open your project's Manage page in VCC or ALCOM and add the Elbow Fixer package.

## How to Use

1. Right-click your avatar in the Hierarchy and select Elbow Fixer > Setup.
2. The body and clothing sleeves are added to Target Meshes automatically. This is still experimental, so you need to check the list in the Inspector.
3. Elbow Fixer is applied automatically when the avatar is built.
